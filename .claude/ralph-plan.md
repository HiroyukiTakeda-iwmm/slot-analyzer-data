# Ralph Plan: スロットデータ拡充計画（イテレーション1更新版）

## タスク概要
- 現在ホールで稼働中の人気スロット台でデータベースに未登録の機種を追加
- 既存データの正確性も検証し、誤りがあれば修正

## 現状
- 登録済み: 56機種
- P-WORLD設置台数ランキングTop20のうち4機種（ジャグラー系）が未登録
- 2025年販売台数Top10は全て登録済み
- 前回検証で主要5機種（マイジャグV、北斗、化物語、いざ番長、カイジ狂宴）は正確性確認済み

## 作業手順（各機種共通）

1. **リサーチ**: ちょんぼりすた・一撃・ななプレスから設定差情報を収集
2. **相互検証**: 複数サイトで確率値を照合
3. **JSONファイル作成**: 既存スキーマに準拠
4. **index.json更新**: エントリ追加

## 既存データ検証（並行）
- 前回未検証の機種からサンプリングで5-10機種検証
- 特にデータが古い機種を優先
